🌊 Catálogo de Animais Marinhos
Este projeto é uma aplicação web desenvolvida com HTML, JavaScript e Bootstrap, que consome dados de uma API mock criada com JSON Server.
O objetivo é apresentar um catálogo de animais marinhos com informações como nome, tipo, descrição e imagem.

✅ Funcionalidades:
Busca de animais por nome.
Exibição de nome, tipo, descrição e imagem do animal.
Estilização responsiva com Bootstrap.
Uso de API local simulada com JSON Server.

🚀 Tecnologias utilizadas:
HTML5
JavaScript (ES6)
Bootstrap 5
JSON Server
